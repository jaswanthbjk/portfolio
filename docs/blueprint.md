# **App Name**: Profolio

## Core Features:

- About Me: Dedicated 'About Me' section detailing professional background and skills.
- Experience Showcase: Interactive 'Experience' section showcasing work history with expandable details for each role.
- Projects Gallery: Visually appealing 'Projects' section with galleries and descriptions.
- Contact Section: 'Contact' section with a functional form and direct contact information.
- Resume Access: Direct link or embedded PDF viewer for resume access.
- Smart Skills Suggestor: AI-powered tool that will offer contextually relevant skills or technologies to associate with each project, based on its description, with options to manually adjust and approve these suggestions.

## Style Guidelines:

- Background color: Dark, desaturated grayish blue (#232931) for a modern, professional feel.
- Primary color: Desaturated grayish white (#CCD2D8) for text to ensure readability against the dark background.
- Accent color: Teal (#4CB5AC) to highlight interactive elements and key sections, providing a vibrant contrast.
- Body and headline font: 'Inter' (sans-serif) for a clean and modern appearance throughout the site.
- Use minimalist icons to represent different sections and functionalities.
- Responsive layout adapting to various screen sizes for optimal viewing on all devices.
- Subtle transition effects on hover and section changes to enhance user experience.
